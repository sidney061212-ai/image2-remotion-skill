# image2-remotion-skill Design

Goal: Build an AI-facing Remotion skill focused strictly on creative multi-image motion compositions.

Scope:
- Strict schema + validation + normalization
- Metadata-only preset selection
- 8 preset registry entries
- 3 implemented presets + 5 placeholders
- Remotion composition entry
- Tests, examples, and AI-facing docs

Non-goals:
- OCR
- Image understanding/classification
- Single-image motion
- Generic slideshow fallback
